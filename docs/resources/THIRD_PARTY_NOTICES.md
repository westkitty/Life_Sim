# Third-Party Notices

**No third-party visual, audio, model, texture, font or code asset bytes are bundled in OpenLife v0.3.0.**

Optional CC0 candidates are documented for future replacement work only. `tools/import_optional_asset_pack.py` stages a manually downloaded ZIP locally and hashes it; it does not perform network access or alter runtime aliases.

See `ASSET_SOURCE_REPORT.md`, `VISUAL_ASSET_MANIFEST.json`, and `AUDIO_ASSET_MANIFEST.json` for exact publisher pages and lifecycle states.
