# Visual Asset Rejections — v0.3.0

- Commercial-game rips or extracted The Sims 3 meshes/textures: rejected. They violate the clean-room purpose and redistribution policy.
- "Free" marketplace assets with unclear per-item licenses: rejected. Free access is not rights evidence.
- Account-gated or paid packs: rejected by explicit project policy.
- Mixed random one-off assets: rejected as the default because they increase style drift and replacement cost.
- Unofficial mirrors: rejected as primary provenance when an original publisher page exists.
- Poly Haven Wood Floor and Asphalt 06: rights/provenance are strong, but rejected as default runtime materials because the realistic PBR density is a poor match for the current low-poly pack and adds unnecessary texture/performance burden.
- Any candidate whose exact downloaded bytes cannot be acquired, hashed, inspected, normalized and Godot-tested: not eligible for `integrated` or `validated` state.
